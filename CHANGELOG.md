# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Fixed

- The verification after a node restart: the identity check tells a refused credential (Access is denied, 0x80070005, HTTP 401) from a node that did not answer (timeout, connection reset or closed, restarting) and retries the latter; the run waits for a node it restarted (port, then session, run setting `restartWaitMinutes`, default 15) before the final verify, with a `NodeWaiting` heartbeat and an honest 'did not come back within N minutes'; a driver install that returns pnputil 3010 is recorded as restart required and the node is restarted once, at the end of the apply.

Registry 5.0.20 registers its parameters; no new infrastructure.yml key.

- `Invoke-AzureLocalOsConfiguration.ps1` and `AzlOsConfigurationRun.psm1`: the whole OS configuration phase for a whole instance in ONE run (`-Mode Plan` or `Apply`). It merges every `*.ztp-handoff.json` under `-HandoffPath`, works out the method per node (a ZTP-provisioned machine over Arc Run Command with only the steps ZTP left undone, or an ISO-installed machine over WinRM with the local administrator from the vault, the computer name, the OS check and Arc registration), plans for all nodes, applies node by node (a failed node does not stop the others), verifies with a Plan pass (a node is converged only when that pass finds nothing left), and writes `report.json`, `summary.md`, `plan-report.json`, `wipe-list.txt` and exit codes 0/1/2.
